## 💻 Fitur Aplikasi Web Interaktif (`index.html`)

Website portofolio ini didesain secara khusus untuk **Technical Recruiters**, **Engineering Managers**, dan **R&D Directors**:

1. **Interactive 3D WebGL Wing Viewer**:
   - Render 3D airfoil NACA & struktur sayap UAV interaktif secara langsung menggunakan **Three.js** dan **OrbitControls**.
   - Kontrol rotasi 360°, zoom, dan wireframe mode secara real-time.
2. **Dynamic CAD 3D vs FEA / CFD Before-After Compare Slider**:
   - Komparasi visual presisi antara model geometri CAD 3D solid dengan visualisasi kontur simulasi tegangan von Mises (MSC Nastran SOL 103 / Inventor FEA) dan hambatan gelombang CFD.
3. **Kalkulator Dinamika Fluida & Faktor Keamanan Struktur**:
   - Perhitungan tekanan dinamis aerodinamika:
     $$q = \frac{1}{2} \rho V^2$$
   - Evaluasi batas tegangan izin & *Safety Factor*:
     $$SF = \frac{\sigma_{\text{yield}}}{\sigma_{\text{working}}}$$
4. **Recruiter Quick-Sheet Modal**:
   - Rangkuman eksekutif 1-klik untuk Headhunter & HR yang memuat ringkasan kompetensi, software mastery, referensi dosen, dan ketersediaan kerja (*available immediately*).
5. **12-Page Full HD PDF Document Viewer**:
   - Navigasi interaktif seluruh lembar portofolio 12 halaman dengan preview thumbnail dan zoom inspeksi.
6. **Bilingual (ID / EN) & Modern Responsive Design**:
   - Dukungan dwibahasa instan, *glassmorphism UI*, dan kompatibilitas mobile penuh.

## 🚀 Cara Menjalankan Secara Lokal

### Opsi 1: Buka Langsung
Klik dua kali file `index.html` pada browser modern apa saja (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).

### Opsi 2: Menggunakan Server Lokal Mandiri
Jalankan perintah PowerShell berikut pada direktori project:
```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```
Buka browser dan kunjungi:
👉 **`http://localhost:8080/`**

## 🌐 Publikasi ke GitHub Pages

Untuk mengaktifkan website ini agar dapat diakses publik di internet secara gratis:
1. Buka repositori ini di GitHub: `https://github.com/syofyanalrisandi/syofyan-alrisandi-portfolio`
2. Masuk ke menu **Settings** > **Pages**
3. Pada bagian **Build and deployment** > **Branch**, pilih cabang `main` dan folder `/ (root)`
4. Klik **Save**. Dalam 1-2 menit, website portofolio akan langsung online di:
   👉 **`https://syofyanalrisandi.github.io/syofyan-alrisandi-portfolio/`**
